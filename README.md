# GoralysCap

Android mobile application for **Goralys**, the Grand Oral subject management platform. This repo contains
the [Capacitor](https://capacitorjs.com/)
wrapper around a static export of the Next.js frontend from
the [Goralys monorepo](https://github.com/SAMSAM-55/Goralys), allowing the existing web app to be distributed as a
native Android app while reusing the entire codebase.

> [!NOTE]
> This repo is kept separate from the main monorepo (web frontend + PHP backend) to isolate the native tooling (Gradle,
Android SDK)
> and its specific build cycle.

## Prerequisites

- Node.js 20+
- pnpm
- Android Studio (with Android SDK, API 36 minimum)
- JDK 21 (recommended for Capacitor 8.x — see JDK note below)

## Setup

```bash
# windows
scripts/setup

# linux
scripts/setup.sh
```

## Development

### Build the web app and sync Capacitor

```bash
pnpm build
npx cap sync android
```

### Run on an Android device/emulator

```bash
npx cap run android
```

Or open the `android/` folder directly in Android Studio for finer control (logcat, native debugger, etc.).

### Debugging the WebView

With a device connected over USB (USB debugging enabled), open:

```
chrome://inspect
```

in desktop Chrome to access the app's DevTools console.

## Icons and splash screen

The icons and splash screen are generated automatically from the sources in `assets/` using the following commands:

```bash
pnpm run assets:generate
npx cap sync
```

See `scripts/patch-monochrome-icon.cjs` for generating the Android 13+ monochrome icon (Material You / Nothing OS),
which isn't natively supported by `@capacitor/assets`.

## Project structure

```
GoralysCap/
├── app/                    # Next.js code (routes, components, hooks — mirrors the web monorepo)
├── assets/                 # Icon/splash sources (pre-generation)
├── android/                # Native Android project generated by Capacitor
├── out/                    # Next.js static export (generated, gitignored)
├── scripts/                # Utility scripts (asset generation, setup, etc.)
└── capacitor.config.ts     # Capacitor configuration
```

## Quirks specific to the Capacitor environment

Unlike the plain web app, a few constraints specific to static export + WebView apply:

- **Mandatory trailing slash**: all routes must end with `/` (`trailingSlash: true` in `next.config`), otherwise
  Capacitor's local asset server resolves them incorrectly.
- **CORS and cookies**: the PHP backend explicitly sets `SameSite=None; Secure` on session cookies to allow cross-origin
  authentication.
- **File uploads**: disabled on mobile (hidden in the UI) due to poor WebView UX; still functional on desktop web.

## Publishing

- **Android**: Google Play.
- **iOS**: not planned in the short term (Apple Developer Program's recurring $99/year fee isn't justified at the
  project's current scale). iOS users can use the responsive web version instead.
